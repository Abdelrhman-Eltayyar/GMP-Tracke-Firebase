## 📋 عن النظام

نظام إلكتروني متكامل لإدارة وتتبع الامتثال لمعايير **GMP (ISO 22716)** في مصنع Pyramids Cosmetics — MPG.

يتيح النظام تسجيل نتائج الفحص الأسبوعي لجميع مناطق الإنتاج والمستودعات والمعامل، وتوليد تقارير الامتثال، ومتابعة الأداء عبر لوحة تحكم تفاعلية — مع مزامنة فورية بقاعدة بيانات Firebase.

\---

## 🏭 المناطق المشمولة

* مخزن المواد الخام والوزن
* مخزن مستلزمات التعبئة والتغليف
* مخزن المنتج النهائي
* مناطق تحضير (كريمات — سوائل — دور أرضي)
* مناطق تعبئة (كريمات — سوائل — دور أرضي)
* مناطق تغليف (دور أرضي — دور أول)
* معمل رقابة الجودة
* معمل الميكروبيولوجي
